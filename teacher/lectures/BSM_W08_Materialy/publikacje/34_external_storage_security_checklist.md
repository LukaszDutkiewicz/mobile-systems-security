# External storage security checklist

- Zrodlo: https://developer.android.com/guide/topics/security/security
- Temat: ekspozycja na external storage

## Teza
- Security checklist wprost ostrzega przed przechowywaniem danych poza kontrola aplikacji i przed dynamicznym kodem z external storage.

## Co czytac
- Data storage
- External storage
- Dynamic code loading warning

## Frazy do znalezienia
- `external storage`
- `dynamic code`
- `content providers`

## Co wyciagnac
- ryzyko modyfikacji i odczytu przez inne aplikacje
