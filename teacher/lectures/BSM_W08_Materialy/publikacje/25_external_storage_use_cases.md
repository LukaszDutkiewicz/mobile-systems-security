# External storage use cases

- Zrodlo: https://developer.android.com/training/data-storage/use-cases
- Temat: ekspozycja na external storage

## Teza
- Ten dokument daje bardziej praktyczny kontekst dla external storage niz same privacy changes, bo pokazuje, kiedy i po co Android w ogole jeszcze dopuszcza storage zewnetrzny.
- Dobrze wspiera argument, ze nie wszystko powinno trafiać do wspoldzielonego storage.

## Co czytac
- Fragmenty o use cases for files and media
- Fragmenty o scoped storage
- Fragmenty o when to use system file picker

## Frazy do znalezienia
- `scoped storage`
- `system file picker`
- `media`
- `user files`

## Co jest na stronie
- Dokument porzadkuje przypadki uzycia i pokazuje, kiedy systemowy picker jest lepszy.
- Wskazuje, ze scoped storage jest domyslnym modelem i ogranicza chaos w external storage.
- Daje dobry kontrast do lokalnego storage i do zagadnienia, kiedy dane staja sie zbyt szeroko dostepne.

## Co wyciagnac
- use-case driven storage policy
- lepszy most do omawiania ekspozycji danych i eksportu plikow
