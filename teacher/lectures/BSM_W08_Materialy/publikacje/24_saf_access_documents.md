# SAF access documents

- Zrodlo: https://developer.android.com/training/data-storage/shared/documents-files
- Temat: Storage Access Framework

## Teza
- To zrodlo domyka SAF, bo pokazuje bezposrednio dostep do shared storage i dokumentow przez systemowy mechanizm.
- Jest lepsze niz sama reference, bo daje praktyczny opis, kiedy aplikacja ma uzyc SAF do interakcji z plikami.

## Co czytac
- Wstep o shared storage
- Fragment o documents provider i cloud/local storage
- Fragment o virtual files i `ACTION_VIEW`

## Frazy do znalezienia
- `documents provider`
- `shared storage`
- `virtual files`
- `ACTION_VIEW`

## Co jest na stronie
- Android mowi, ze SAF dziala z providerami dokumentow i obejmuje tez zewnetrzne oraz cloud storage.
- Virtual files pokazują, ze dokument nie musi byc zwyklym plikiem binarnym.
- To ważne, bo lekcja o SAF moze pokazac, ze systemowe API jest bardziej ogolne niz zwykly file picker.

## Co wyciagnac
- rozszerzenie SAF na shared storage
- praktyczny punkt odniesienia dla tematu eksportu danych
