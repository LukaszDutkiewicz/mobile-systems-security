# Security checklist dynamic code

- Zrodlo: https://developer.android.com/guide/topics/security/security
- Temat: dynamiczne ladowanie kodu

## Teza
- Security checklist laczy dynamic code loading z external storage i podpisami, co pokazuje praktyczny kontekst zagrozenia.

## Co czytac
- dynamic code loading warnings
- external storage
- code verification

## Frazy do znalezienia
- `dynamic code`
- `signed and cryptographically verified`
- `external storage`

## Co wyciagnac
- kod spoza APK jako obszar wysokiego ryzyka
