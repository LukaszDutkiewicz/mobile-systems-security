# Open document tree

- Zrodlo: https://developer.android.com/guide/topics/providers/document-provider
- Temat: Storage Access Framework

## Teza
- `ACTION_OPEN_DOCUMENT_TREE` pokazuje, ze SAF nie dotyczy tylko pojedynczego pliku, ale tez calego drzewa dokumentow.

## Co czytac
- `ACTION_OPEN_DOCUMENT_TREE`
- `ACTION_OPEN_DOCUMENT`
- persistable permissions

## Frazy do znalezienia
- `ACTION_OPEN_DOCUMENT_TREE`
- `persistable permissions`
- `document tree`

## Co wyciagnac
- drzewo dokumentow jako precyzyjnie kontrolowany zakres
